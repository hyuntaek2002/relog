# 사용자 평가 참여 안내 및 동의서

과제: 생성형 AI 대화의 반복·비효율 패턴 온디바이스 탐지 및 개인화 활용 전략 추천·평가 시스템 (relog)
수행: 선문대학교 AI소프트웨어학과 강현택 (지도: 김정동 교수)

## 1. 평가의 목적

일반 추천(누구에게나 같은 인기 기능)과 개인화 추천(내 대화 패턴에 맞춘 것) 중 어느 쪽이 더 관련 있어 보이는지 알아보는 탐색적 평가입니다. 참여 인원이 적어 결과를 일반화하지 않습니다.

## 2. 참여 방법 (약 15분)

1. 본인의 ChatGPT 또는 Claude에서 대화 내보내기 파일을 직접 내려받습니다.
2. 본인 컴퓨터의 브라우저에서 relog 평가 화면을 열고 파일을 넣습니다. 분석은 그 브라우저 안에서만 이뤄집니다.
3. 화면에 섞여 나오는 추천 카드를 보고 관련성 점수(1~5점)를 매깁니다. 어느 카드가 개인화 추천인지는 표시되지 않습니다.
4. 1주 뒤, 추천받은 기능을 실제로 써 봤는지 한 번 답합니다(선택).

## 3. 수집하는 것

- 추천 카드별 관련성 점수와 카드가 제시된 순서
- 추천 종류(일반/개인화)와 추천 항목의 식별자
- 요금제 구분(무료/유료 등)과 이미 쓰는 기능 체크 여부
- 주 단위 집계 숫자: 메시지 수, 대화 종류별 메시지 수, 다시 말한 지시로 표시된 건수와 비율, 분량 추정치, 시간대별 메시지 수
- 1주 뒤 실제 사용 여부(예/아니요)

## 4. 수집하지 않는 것

- 대화 내용(내 메시지와 AI 답변의 글)과 대화 제목
- 내보내기 파일 자체
- 문장을 숫자로 바꾼 값(임베딩)
- ChatGPT·Claude 계정의 아이디, 비밀번호, 결제 정보
- 이름, 연락처 등 개인을 알아볼 수 있는 정보(참여자는 번호로만 구분합니다)

파일은 참여자의 브라우저 밖으로 나가지 않습니다. 평가 화면의 "네트워크 감사"에서 바깥으로 나간 요청을 직접 확인할 수 있습니다.

## 5. 보관과 삭제

- 수집한 숫자는 과제 종료(2026년 12월 14일) 뒤 결과 보고서와 논문 작성에만 쓰고, 2027년 2월 말까지 삭제합니다.
- 참여자는 언제든 이유 없이 참여를 그만둘 수 있고, 그만두면 그때까지 수집한 본인 자료를 삭제합니다.
- 결과는 참여자를 알아볼 수 없는 통계로만 발표합니다.
